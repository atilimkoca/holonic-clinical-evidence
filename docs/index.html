S6 Inconsistency Corpus Statistics

The inconsistency benchmark contains 100 holons: 50 consistent controls and 50 inconsistent cases. The inconsistent cases are distributed across six defect types. Table Table S2 reports the type-level counts and detection outcomes.

Sets A and C have no false positives and no false negatives on the injected corpus; none of the three sets flags any of the 50 consistent controls. Set B also has no false positives, but misses all boundary-dependent defects T4–T6. This explains why Set B precision remains 1.00 while recall falls to 0.52 and F1 to 0.68.

S7 Statistical Test Details

This section gives the statistical test choices, assumption checks, and effect-size reporting used in the main experiments.

S7.1 SHACL Validation Comparison

The validation comparison is paired because Set A and Set B are applied to the same holons. Therefore, McNemar's test is used for paired binary correctness. The contingency table is given in Table Table S3.

The discordant counts are A-right/B-wrong = 24 and A-wrong/B-right = 0, yielding p=1.192×10−7. The bootstrap 95% confidence interval for the recall difference is [0.34, 0.62].

S7.2 GraphRAG Conformance

For first-pass conformance, System A is correct on 100 paired cases where System B is not, yielding McNemar p=1.578×10−30. For converged conformance, the discordant count is 34 in favour of System A, yielding p=1.164×10−10.

S7.3 Hallucination Rate

Per-question hallucination differences are non-normal according to the Shapiro–Wilk test (p=5.374×10−13); therefore, the Wilcoxon signed-rank test is used. The Wilcoxon test gives p=2.087×10−19, and the reported Cohen's d is 23.27. Bootstrap 95% confidence intervals are [0.000, 0.000] for System A and [0.754, 0.766] for System B.

S7.4 Grounding-Label Stability

The internal stability check compares the rule-based grounding labels with a deliberately perturbed second automated pass over 110 generated assertions, yielding Cohen's κ=0.78. This is not human inter-annotator agreement and does not establish a human gold standard; it measures stability of the automated labelling procedure under the declared perturbation.

S8 Neo4J Cypher Query Examples

This section documents the Cypher export generated for the Neo4J/n10s portability path. The import and benchmark scripts are produced from the holonic RDF export and are included as artifacts; the measured query benchmark in this study uses rdflib SPARQL, and no Neo4J timings or cross-store comparisons are reported.

Clinical-semantic status. The historical export records 136 TREATS and 68 CAUSES_SIDE_EFFECT edges corresponding to the 204 canonical benchmark assertions. The Cypher projection does not carry the assertion-to-source links needed to verify those predicates clinically. These edges exercise storage, querying and validation and must not be interpreted as curated therapeutic recommendations; relation-level validity depends on the cited source and extraction context in the authoritative RDF release. All Cypher clinical edges therefore require source-level verification before clinical reuse. Table Table S4 records the specifically reviewed high-risk examples. The two prednisone–osteoporosis TREATS edges are preserved as comments but quarantined from execution because the available projection provides no supporting source mapping and the direction is clinically suspect; the reported RDF corpus counts and experiments are unchanged because the Neo4J import was outside the measured benchmark.
